# language

This folder contains selected tests to monitor the cost of various language features. The collection is expected to grow in the future.

* For - list append and for-in summation
* ForIn - nested for-in loops with function calls
* ListCreation / TupleCreation - allocation of small collections
* ListLookup - hot list indexing
* Loop - tight numeric loop
* Matrix - linear solve via Matrix
* Metafunction - typed overload dispatch
* MethodCall - object method call chains
* MethodLookup - typed method lookup microbench
* Pow - power operator hot loop
